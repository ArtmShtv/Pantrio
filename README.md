# Pantrio

Meal-planning app MVP: weekly meal plans, pack-aware shopping lists with prices,
calories and macros, and a pantry of leftover ingredients.

## Stack

FastAPI · SQLAlchemy 2.0 (async, asyncpg) · Alembic · PostgreSQL · PyJWT · pwdlib (Argon2) · Authlib

## Getting started

Requires [uv](https://docs.astral.sh/uv/) and Docker.

```bash
cp .env.example .env          # then fill in secrets
uv sync                       # create .venv and install deps
docker compose up -d          # start Postgres
uv run alembic upgrade head   # apply migrations
uv run fastapi dev app/main.py
```

- API docs: http://127.0.0.1:8000/docs
- Liveness: `GET /health` · Database check: `GET /health/db`

## Common commands

```bash
uv run pytest                                         # tests
uv run ruff check . && uv run ruff format .           # lint + format
uv run alembic revision --autogenerate -m "message"   # new migration after model changes
uv run alembic upgrade head                           # apply migrations
uv run alembic downgrade -1                           # undo last migration
```

Always read an autogenerated migration before applying it: Alembic can't detect
renames (it sees a drop + add) and misses some changes such as check constraints.

## Layout

```
app/
  main.py         app factory: middleware, routers, lifespan
  core/config.py  Settings, read from env/.env (the only place env vars are read)
  db.py           engine, session factory, Base, get_session dependency
  models/         SQLAlchemy models (import each one in models/__init__.py)
  schemas/        Pydantic request/response models
  services/       business logic (plans, shopping list, pantry)
  auth/           password hashing, JWT, get_current_user, OAuth
  api/routes/     HTTP endpoints, thin: validate -> call service -> return
migrations/       Alembic
tests/
```
